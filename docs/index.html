Deleuze GraphRAG

Rhizomatic knowledge graph for Deleuzian philosophy

What is this?

A GraphRAG pipeline that transforms Gilles Deleuze's philosophical corpus (books and seminars) into a queryable rhizomatic knowledge graph. It combines:

  • Graph-based concept extraction via GraphRAG
  • Quote-level vector search with Cohere embeddings
  • A nomad agent that routes queries between both systems

The Pipeline

  • Corpus preparation — PDF to cleaned text + semantic chunks
  • Prompt tuning — Bilingual extraction respecting Deleuzian ontology
  • GraphRAG indexing — Entity/relationship extraction with community detection
  • Vector index — Quote-level embeddings for exact passage citation
